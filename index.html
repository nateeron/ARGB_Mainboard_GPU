คู่มือการใช้งาน

1) เชื่อมบอร์ด (หน้าเว็บ)

  • Board IP — IP บอร์ด (DHCP จากเราเตอร์ — ดูจาก getip / BLE Get IP)
  • WiFi — เปิด dialog ตั้ง WiFi Name / Password / IP
  • Connect — บันทึก IP + เชื่อม HTTP API

2) ปุ่มใน WiFi Dialog

  • BLE Get IP — ดึง IP จาก Bluetooth Cayoshi_RGB (Chrome/Edge)
  • Save — บันทึก WiFi + IP (เว็บ + บอร์ด Flash + history 5 แถว)
  • Test Connect — ทดสอบ HTTP /api/status (บันทึก WiFi ด้วย)
  • Connect — ส่ง WiFi ให้บอร์ดต่อใหม่ + รับ IP กลับ
  • Close — ปิด dialog (คลิกพื้นหลังไม่ปิด)

3) Serial Monitor (115200 baud)

setwifi Cayoshi2.4g asd112233 wifi scanwifi wifistatus getip reset
  • setwifi <ssid> <password> — ตั้ง WiFi บันทึก Flash
  • wifi — ใส่ SSID แล้ว password ทีละขั้น
  • scanwifi — สแกน WiFi รอบๆ
  • wifistatus — ดู SSID ที่บันทึก
  • getip — แสดง IP ปัจจุบัน

4) Bluetooth (BLE)

  • ชื่ออุปกรณ์: Cayoshi_RGB
  • ใช้แอป nRF Connect / LightBlue สแกนหา
  • อ่าน characteristic เพื่อดู IP WiFi
  • Arduino IDE: Tools → Bluetooth → Enabled หรือ NimBLE

5) บอร์ด (app_config.h)

  • WiFi: DHCP (IP อัตโนมัติจากเราเตอร์)
  • HTTP API: port 80 — /api/status, /api/wifi, /api/settings

6) แก้ปัญหาเบื้องต้น

  • เชื่อมไม่ได้ → ตรวจ IP, WiFi บอร์ด, เปิด Live Server / HTTPS
  • หา BLE ไม่เจอ → อัปโหลดสเก็ตช์ใหม่, เปิด Bluetooth ใน Arduino IDE
  • เปลี่ยน WiFi แล้ว IP เปลี่ยน → กด BLE Get IP หรือ getip ใน Serial
